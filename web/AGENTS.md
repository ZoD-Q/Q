# 小Q 独立 Web 补充规范

先读 [根协作规范](../AGENTS.md)。当前目录已提供 React / TypeScript / Vite 管理工作台静态演示原型，路径 `/q-admin/`；普通用户独立 Web 产品与真实后台接口仍未交付。

- 用户网页、开发者工作台与运营界面按实际任务建设；开发者和运营权限分开，页面隐藏不能代替服务端鉴权。
- 按需复用 `../mobile/shared/` 的合同类型与纯逻辑，不直接依赖原生 UI，不在 Web 客户端实现账本或保存服务密钥。业务后端位于 `../backend/`。
- 接口以 [API 合同](../backend/contracts/api.md) 为准，生成类型不得手改；不要为网页单独造一套身份、金额或错误语义。
- 实际插件功能遵循 [插件规范](../backend/docs/plugin-integration.md)，可选开发者工作台不能成为开放插件接入的注册或审核门槛。
- 建设新页面时保持 Q 的对话首页、服务侧栏、白底青蓝和双语方向，并验证键盘操作、焦点、对比度、窄屏与加载/错误状态。
- 本原型的演示数据、操作和管理员切换只存在内存；不添加真实凭据输入、业务请求或持久化，不将能力基础标签视为管理接口已接通。
- 改动运行 `npm --prefix web run typecheck`、`lint`、`test`、`build` 与 `test:e2e`（各使用同一前缀）；部署脚本变更同时运行Shell语法与Python测试。更新本目录README和验证记录，不把Expo预览或静态演示写成真实运营能力。
