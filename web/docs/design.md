# 小Q管理工作台设计

本轮是完整产品范围的静态交互原型，公开演示，不连接业务服务。数据为明确虚构的2026-10-19场景，刷新重置。

视觉沿用项目白底青蓝：白色 #ffffff、底色 #f5f8fa、正文 #243541、次文字 #627580、强调 #087fa3、强调浅底 #eaf6fa。语义变量支持dark/warm；状态同时用文字与图标表达。中文系统字体PingFang SC/Microsoft YaHei，拉丁系统sans-serif，数字等宽对齐，不请求远程字体。

左侧228px导航负责稳定定位，中央待处理列表是首页焦点；右侧气泡Q只用于当前场景摘要。信息按“概览→列表→详情→有理由的操作”展开。避免营销大标题、装饰性渐变和多重弹窗。桌面详情用原生dialog，窄屏改为全宽；键盘焦点、取消、返回位置与减少动态效果保持可用。

侧栏折叠方向参考 https://ui.aceternity.com/components/sidebar ，本项目自行实现，不复制其源码或引入Motion/Tailwind。UI/UX Pro Max自动生成的营销落地页结构不适用，因此使用仓库已确认的视觉基线。气泡Q图片为用户此前生成并选定的原图，按原文件复制，不重绘。

能力基础与演示运行状态分开：existing/branch/planned只说明代码基线，任何状态、金额、用量和操作日志均为演示。公开原型不提供真实登录框、密钥输入或业务请求。
