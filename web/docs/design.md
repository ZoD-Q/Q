# 正式后台设计（2026-11-06）

正式工作以付款记录和证据为中心。首屏是Q登录；获服务端授权后进入支付队列，四个导航依次为审核退款、结算储备、参考汇率、支付域审计。没有聚合接口时不放统计卡，不把某页数量冒充总量。历史演示模块不再可达，旧地址说明未接入。

视觉严格遵守用户的三色要求：黑`#000`作为所有底面，青`#0ff`作为内容、焦点与主要操作，红`#f00`标识错误/危险；边框和弱层次只用这三色的透明度。字体使用系统Avenir Next/Segoe UI/PingFang SC，无外部字体依赖。正文16px，按钮至少44px（主要48px），桌面表格与窄屏自身滚动区分别处理，不让整个页面横溢。

状态有文字；成功空页只在请求成功后显示，失败不显示0，过期结果须注明时点并锁住依赖最新证据的写操作。审批与退款确认绑定当前对象、金额和版本；单次确认框不堆叠。原生dialog提供焦点约束和返回；文件内容不内联执行。手动日期输入避免浏览器自带日历引入其他配色，严格校验本机日历值并保留毫秒。

复用原工作区的表格、事实列表、恢复和确认行为，不复制第三方组件或增加UI框架。frontend-design与UI/UX Pro Max用于层级、对比度、焦点和窄屏检查；设计系统查询偏营销页，未采用其建议配色。旧彩色形象文件从新制品删除，历史版本留在Git中。
