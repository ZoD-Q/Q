# 金融数据研究工具（公开源）

2026-10-27。用户将小Q的主方向调整为金融市场研究，并要求先使用无需 API 权限的公开源。本轮从首页移除账单整理、分期成本、储蓄目标三个功能入口，保留金融知识，新增“金融数据”入口。完成本地验收后，用户已恢复推送 Mandow 并提交人工审核 MR 的授权；不自动合并或部署。

## 已实现的本地路径

首页或插件页 → 金融数据 → 选择币种、公司或新闻主题 → 点击查询 → 核对来源、数据时点与获取时间 → 点击“本次资料来源”旁的“用于对话” → 选择新建小Q对话或历史 AI 对话 → 进入带资料的草稿。长列表底部也保留入口。

资料以可读的研究草稿呈现，包含来源、时间、缺失项和使用限制，不向普通用户展示原始 JSON。资料不会自动发送给模型；用户仍需登录、按既有 AI 分享许可并主动发送。新对话不带入旧本地财务记录、银行连接或账号令牌；选择普通历史 AI 对话会保留该段对话已有的正常上下文。插件、本地财务或含工具结果的对话不接收研究草稿，历史摘要不含插件身份时还须读取详情后核验。已有未发送草稿、进行中的请求或待确认历史写入会阻止带入；加载失败、取消、切号或用户新输入不能清掉原会话和草稿。普通非插件 AI 问答也加入市场研究指引：没有当前来源不能编造实时价格或新闻，引用外部资料时区分事实、推断和情景；广告不作为证据。

这里的“金融数据工具”是小Q内置的匿名只读数据适配，**不是已发布的远程 MCP 服务**。现有 MCP 发现、个人连接、授权与业务确认保持独立。本轮没有新增服务器、数据库、交易能力或商用数据授权。

## 数据源与真实边界

| 能力 | 数据源 | 边界 |
| --- | --- | --- |
| BTC / ETH / SOL 美元参考价 | Ethereum 上的 Chainlink Data Feeds，经 Alchemy 公共 RPC 只读获取 | 正式与开发构建使用同一路径；仅价格和链上更新时间，不提供24小时变化、成交量或市值，不是交易所成交报价。无需钱包或供应商密钥 |
| 美国公司公告 | SEC submissions，AAPL / MSFT / NVDA | 最近公开申报文件，不是美股报价。公告日、报告期和受理时间分开显示 |
| 宏观新闻 | 美联储货币政策 RSS | 官方公告标题、短摘要和原文链接，不代表所有财经新闻 |
| 全球财经、加密、科技新闻 | GDELT DOC 2 公开 JSON | 仅元数据，索引时间不等于发布时间；本机探测曾返回 429，遇限流保持错误，不换源伪装成功 |

热点只对本次返回样本做去重、规则主题归类和计数，不是全网热度榜，也不代表相关事件造成了价格变化。正文不爬取、不绕过付费墙，原文仅在用户确认后打开。

金十已有官方 MCP 文档；同花顺 iFinD 有官方 HTTP API；Alpaca 和 Massive 可提供美股数据，其中 Massive 另有官方 MCP。这些服务在本页都标为“需官方权限，未连接”，只提供公开说明入口，没有密钥输入、自动授权或后台凭据查找。没有调用这些服务的认证接口。

## 网络与数据处理

- 请求地址由工具类型和固定选项生成，不接受任意请求 URL。新闻和公告使用 HTTPS GET；链上参考价使用固定 JSON-RPC POST 批量读取链 ID、feed 小数位和最新轮次。POST 在这里仅查询，不签名、不广播交易，不接受任意方法、合约或 RPC 地址。所有公开源均不发送 Q 会话、Cookie、Authorization 或个人数据。
- 使用现有 `expo/fetch`，显式 `credentials: omit` 与 `redirect: error`。Expo 58 的 iOS/Android 原生实现会拒绝跟随；收到重定向或不匹配地址仍拒绝。
- 10 秒总超时、AbortController、512 KiB 流式字节上限；没有可用流读取器时拒绝，不先读完整响应再判大小。失败不自动重试。
- 新增纯 JavaScript `fast-xml-parser` 5.11.2，仅解析有界美联储 RSS；拒绝 DOCTYPE/ENTITY，不执行 HTML/脚本，无新原生模块。
- 行情缺失值保持为空，不补零；资产和公司身份需匹配请求，日期和数值在边界校验。源时间与获取时间独立显示，过期数据标明限制。
- 查询由用户点击触发，没有轮询。切换选项、离页、后台会取消在途请求；迟到结果不能覆盖当前查询。只保留有界内存公开缓存，不建立用户财务画像。
- 正常同源间隔为 SEC 至少 1 秒、币种/美联储至少 2 秒、GDELT 至少 5 秒；相同查询在缓存有效期内不外发。429 至少冷却 60 秒，并尊重更长的 Retry-After。内存冷却跨页面重建保留，但不冒充跨设备或供应商全局配额控制。
- 新闻标题、摘要及第三方页面文字始终是不可信数据。研究草稿限制长度、保留来源和时间，不把文章中的指令提升为宿主权限，不执行购买或交易。

SEC 本次匿名探测返回可跨域响应，但其官方文档不保证 CORS；美联储 RSS 没有跨域允许头。因此原生端与 Web 的可用性须分别验证，Web 失败不通过未知代理绕过。

## 首页调整与历史兼容

首页快捷项、输入框工具入口、工具弹层和本地详情不再打开三类旧计算工具；知识弹层强制只显示知识。旧计算核心及已有结果保留供兼容，不清理数据。遗留账单/分期/储蓄命令在普通对话路径本地说明已移除，不重新计算，也不能因移除而落入云请求。市场与公司收入问题和个人账单输入区分。

新建市场研究标题使用“市场研究 · / Market research ·”，旧财务问答标题仍可恢复。标题只用于问答模式，不授予数据源权限。

## 2026-11-01 修复

正式版不能查币种的原因是旧 CoinPaprika 来源按 `__DEV__` 禁用。用户明确选择改用公开链上参考价，因此移除对构建模式的判断并替换来源，不能将旧源限制解除描述为已取得商业数据授权。只读 RPC 校验链 ID、请求 ID、合约返回、小数位、正价格和轮次时间，来源页面指向实际 feed。不同 feed 的更新周期不同，源时间与本机获取时间独立保留。

新“用于对话”入口只填草稿，不自动调用大模型或写云历史；历史对话读取与最终提交之间核对身份、页面、输入和选择代次。界面沿用三主题、双语及至少48的触控目标，无新UI依赖。

本轮验收：类型检查、ESLint、Web 导出、七组移动端测试共 469 项全部通过，0 失败/跳过；差异检查通过。独立复核覆盖固定只读 RPC、ABI/时间校验、草稿长度（含模型指引）、切号/后台/取消/并发和历史详情二次校验，无遗留 P1/P2。查询实现不依赖 `__DEV__`，生产路径有独立回归；未打包或上传新安装包。

iPhone 17 / iOS 26.5 / Expo Go 58.0.4 实际读取 BTC、ETH 参考价成功，来源时点与获取时间分开显示。来源按钮旁的“用于对话”以及新建、已有普通 AI 对话的草稿带入均实测通过，未点击发送。BTC/ETH/SOL 的匿名公共 RPC 探测均成功；没有真机 Android、发布安装包、深色/暖色、最大字体或浏览器跨域验收，Web 导出不能代替这些检查。公共 RPC 无可用性承诺，失败仍明确报错，不自动切换不明节点或降级为虚构价格。
