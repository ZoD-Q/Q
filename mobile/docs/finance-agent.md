# 本地财务助手与广告位演示

2026-10-27，基于已审核主线 `aa24601` 的本地开发。本轮没有新增 API、数据库迁移、真实机构接入、营销投放、支付或部署。

## 主对话

首页保留对话中心，提供账单、分期成本、储蓄目标、金融知识四个入口。工具提交后创建新的本地财务对话；原有云端对话及银行插件保持独立。主输入框也接受下面的明确格式：

```text
账单 CNY
收入 工资 12000
支出 房租 3000
支出 餐饮 980.50

分期 CNY 8000 12 240
储蓄 HKD 50000 10000 2000
```

分期参数依次为本金、期数、全部费用；储蓄参数依次为目标、已有金额、每月存入。支持的币种为 CNY 和 HKD，不做汇率换算。未知字段、混合币种、负数、指数、小数位超限及整份账单中的错误行不会被猜测或跳过。重复账单提示行号但保留计数，避免误删真实的重复消费。汇总仅代表输入的记录，不代表整月完整账单或银行余额。

金额以整数分计算，拒绝超出安全整数范围的输入及总额。分期最多 60 期，总本金与费用按分分摊，余数优先计入前几期，逐期合计保持一致。有效年化按逐月现金流 IRR 测算，假设现在收到全部本金、一个月后首期、此后每月一次，费用一并分期偿还；不等同所有地区的法定 APR，也不是银行报价，不含未输入的费用。储蓄只做固定月存入的向上取整计算，不预测收益。

金融知识为 8 条双语编辑内容，带官方来源和核对日期；点击来源才打开外部网站。不提供实时行情、个性化产品推荐或承保结论。

## 数据与 AI 的边界

- 本地财务会话使用新 ID 与 `localOnly` 标识，消息同时标记 `localFinance`。不把既有云会话改成本地，不把本地会话直接转换为云会话。
- 本地表单、账单及结果只在当前进程内存中保留；表单关闭或隐私代次变化时卸载。游客登录、退出、切号或重新加载会清除本地记录及草稿。不保存到 SecureStore、localStorage、云端历史或日志。
- 历史序列化、模型上下文、发送/重试、插件恢复与续答均拒绝本地财务数据；打开本地历史不访问云端详情。模型和广告模块不接收本地结果对象。
- 应用原有状态探测、账号及历史列表仍可能联网，不能称整个应用完全离线。测试核对的是本地财务内容没有进入任何请求，以及本地会话没有产生历史写入、模型或工具调用。
- “新建 AI 金融问答”创建另一段空对话，不带入本地记录或旧草稿。用户重新填写需要分享的问题，沿用既有 Q 登录和 DeepSeek 分享许可。请求加入公开的金融知识问答指引，但它不是金融资质或业务授权。
- AI 金融对话使用可见标题前缀“财务问答 ·”或“Finance Q&A ·”，通过现有历史合同恢复问答模式；前缀只改变模型指引，不授予插件、账户或交易权限。
- 本地对话最多 100 条消息，单条主输入最多 12,000 个 Unicode 码点；超限显示原因，不能回退到云端发送。表单最多整理 500 笔、50,000 字符，错误时保留输入。

## 广告位演示

分期、保险和理财各自展示一个独立广告位，显著标为“广告位演示 / 无真实广告合作”。三项活动使用虚构示例合作方，无真实品牌赞助声明、利率承诺、产品申请或外部投放。理财入口本轮改用已有官方公开资料目录；公开资料不代表机构合作，不能与邻近的演示广告混为一体。

活动选择只接收服务类别、活动状态、时间和本机偏好，不接收对话、身份、余额、交易或财务任务数据。每项活动在一次应用会话最多展示 3 次，以服务页进入为单位去重；页面重新渲染不增加展示。详情点击仅表示打开演示详情，不代表申请或成交。计数仅在内存，不发送后台。

单项关闭与全部拒收分别处理；拒收持续生效，只能由用户手动开启，开启总开关也不会恢复单独关闭的活动。偏好仅保存 `enabled / hiddenCampaignIds`：原生使用已有 SecureStore，Web 使用非敏感 localStorage。读取完成前或读取失败时不展示；写入失败保留当前拒收、展示错误并提供重试。保存串行化，旧读取或迟到保存不得覆盖新的拒收。

这不是广告交易平台，没有真实商户后台、素材审核系统、商业预算扣减或成交归因。正式金融营销需另行落实市场、资质、合同、经审素材及机构承接流程；不能把本地演示开关当作上线授权。

## 验证

适用检查为移动端 typecheck、lint、utils/video/plugins/api-workbench/account/social/chat 测试、Web 导出及原生页面检查。新增财务与广告测试已纳入 `test:chat`，现有 GitLab mobile-check 会随之覆盖；本地结果不代表远端流水线运行。

独立 review 已修复并复验：长 UTF-16 财务输入误走云请求、AI 金融历史重开后模式丢失、本地错误详情未显示。测试覆盖整数分守恒、IRR 现金流验证、整份账单失败、重复保留、币种与金额边界、隐私标记、游客登录/切号清理、插件隔离、广告频控及偏好异步竞态。

本机预览使用前端开发服务器 `8093`。API 仍为默认长期服务，未启动数据库或本地 API；本地财务工具不需要登录。iOS 验收使用 Expo Go 58.0.4 与 iPhone 17 / iOS 26.5，不上传 TestFlight、不替换生产服务。

验收入口：

1. 首页“整理账单”→“填入虚构示例”→“整理到本地对话”，查看分类与逐笔明细。
2. “分期成本”输入本金 8000、全部费用 240、12 期，核对总还款 8240 及每期金额；再测试错误输入。
3. “储蓄目标”输入 50000 / 10000 / 2000，核对 20 个月；每月存入为 0 时显示不可达。
4. 打开知识条目，核对通用知识及官方来源；不把它当作在售产品推荐。
5. “金融服务”进入三类专区，查看演示广告、说明和关闭；在“广告设置”关闭全部，重新进入页面仍不展示。
6. 从本地结果点击“新建 AI 问答”，确认没有带入账单；是否登录和发送问题由验收者选择。

- 类型检查、Lint、Web 导出和 `git diff --check` 通过；7 组移动端测试共 **393 项通过、0 失败、0 跳过**：utils 31、video 10、plugins 83、api-workbench 16、account 44、social 33、chat（含财务和广告）176。
- 两份独立源码 review 的 3 个 P2 问题均修复并复验，最终没有遗留 P1/P2。横屏原生检查发现输入区偏高，收紧本地紧凑布局后再次检查和只读 review 通过。
- iPhone 17 / iOS 26.5 / Expo Go 58.0.4 实际完成：虚构账单 5 笔，收入 12,000、支出 4,730.50、结余 7,269.50；8,000 本金、240 总费用、12 期总还款 8,240，年化估算显示 5.63%；12.5 期被拒绝并保留输入；50,000 / 10,000 / 2,000 的储蓄结果为 20 个月；APR 知识卡进入主对话并显示来源。
- 分期广告的虚构合作标识、详情原因、展示/点击计数通过；关闭全部广告后重新加载仍保持关闭，计数归零。检查后手动恢复演示开关，供用户验收。工具→财务表单、工具→金融服务、金融服务→广告设置的原生弹层转场正常。
- 中文白昼、英文夜色及横竖屏实际检查通过；数字键盘下提交按钮可见。最终恢复中文白昼竖屏首页，开发服务器保持运行供验收。
- 实际预览没有登录或提交真实金融资料，没有调用付费模型、银行写操作或机构业务；金融 AI 的请求指引、历史恢复和数据隔离由真实 hook 的替身网络测试覆盖。真实 DeepSeek 回答仍需用户登录后另行验收。

Android、真机、iPad、最大系统字体、系统 Reduce Motion 开关、暖纸主题和真实金融机构业务尚未逐项实测。本节记录本地验收；提交、MR 和远端 CI 状态以对应记录为准，未部署本轮代码。
