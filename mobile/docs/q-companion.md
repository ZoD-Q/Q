# 气泡小Q与对话首页

2026-10-26 创建，2026-10-27 对齐插件对话合并后的源码。本次把选定的气泡小Q形象用于聊天首页和回答状态，并重新组织首页文字、状态提示与输入区。这里只记录客户端源码行为，不代表服务器、安装包或应用商店版本已经更新。

## 形象适配

选定形象为青蓝水润圆身体、右下 Q 尾尖、深蓝椭圆眼睛和简洁嘴形，不增加手脚。原图 [q-bubble-icon.png](../native/assets/brand/q-bubble-icon.png) 保持原样。本次新增的 [QCompanion](../native/src/prototype/ai-chat/q-companion.tsx) 是对该形象的原生 SVG 适配，使用渐变、轮廓反光和不同表情；它不是对原 PNG 的逐像素复现，也不替换应用图标文件。

向量版背景透明，可放在 light / dark / warm 三种主题的页面中。气泡主体使用集中定义的品牌青蓝色，角标和状态文字使用现有主题的语义色。每个实例使用独立渐变标识，支持同屏多个头像。小于 48 的头像隐藏角标和底部投影；当前消息头像为 30，主状态栏为 52，详情中的形象为 64，空态展示为手机 152、宽屏 176。

角色适配和首页布局本身复用已有 `react-native-svg`、Reanimated 和 `useDesign`，没有新增依赖或修改 API 合同。合入的插件自动只读能力及其合同兼容另见 [插件对话设计](plugin-chat-2026-10-26.md)。

## 八种视觉状态

状态由 [mascot-state.ts](../native/src/prototype/ai-chat/mascot-state.ts) 从现有聊天阶段、最新消息和请求结果映射，仅负责呈现，不发送、重试或恢复业务请求。中文和英文标题均随实际原因变化，同一种表情不等于同一种故障。

| 视觉状态 | 当前文案与触发条件 | 形象与角标 |
| --- | --- | --- |
| `ready` | “小Q在这里 / Q is here”。当前没有更高优先级的进行中、完成或异常状态。 | 日常微笑、脉冲线角标；首页空态隐藏该角标。 |
| `thinking` | 请求等待为“正在准备回答 / Preparing an answer”，思考阶段为“思考中 / Thinking”；接收结束但最终记录尚在保存时为“正在保存回答 / Saving the answer”，插件步骤记录收尾时为“正在保存对话 / Saving the conversation”。也用于“正在恢复登录 / Restoring your session”“正在同步对话 / Syncing conversations”“正在准备对话 / Preparing chat”，对应各自真实进行中的操作。 | 目光向上、小圆嘴、三个圆点。 |
| `streaming` | “正在回答 / Answering”。正在接收回答内容，可使用现有停止操作。 | 专注表情、连续箭头。 |
| `interrupted` | 意外断流为“回答已中断 / Answer interrupted”；超时为“等待超时 / Response timed out”；未完整结束或达到长度上限为“回答未完整结束 / Answer incomplete”。恢复的未完成历史也按中断处理。 | 担忧表情、断开的箭头。 |
| `paused` | 用户停止为“已停止 / Stopped”。还用于“请重新登录 / Sign in again”“请稍后再试 / Try again shortly”“请检查输入 / Check your message”等需要用户处理的状态；插件 `tool` 消息显示“查看插件状态 / Review plugin status”，续答失败显示“暂时无法继续回答 / Could not continue the answer”。 | 平静的短线嘴、暂停符号。 |
| `offline` | `NETWORK_ERROR` 显示“连接异常 / Connection problem”。只说明这次连接失败。 | 担忧表情、划线网络符号。 |
| `error` | 根据原因显示“历史尚未同步 / History not synced”“对话暂不可用 / Chat unavailable”“连接检查未完成 / Connection check failed”或“暂时无法回答 / Could not answer”。 | 严肃表情、警告三角。 |
| `complete` | “回答完成 / Answer complete”。最新助手回答已完整结束且内容非空，当前没有尚在进行的最终保存、同步或其他更高优先级阻碍。 | 笑眼、对勾。 |

需要保留的语义边界：

- “小Q在这里”不表示系统健康、供应商额度充足或下一次调用必然成功。公开配置检查也不是实时健康检测。
- `offline` 是内部视觉状态名，界面不据一次请求失败宣称设备已经断网。
- “已停止”保留已经收到的文字；重试会重新生成回答，不承诺从断点续传。意外断流不伪装成用户主动暂停，也不算完成。
- `tool` 消息不能证明工具仍待确认、已经成功或可以再次执行。当前业务状态与可用操作以插件卡片为准，角色只提示“查看插件状态”。
- “回答完成”只描述本次模型回答，不代表插件交易或其他业务已成功。
- 接收结束后仍需等待最终历史写入；此时显示“正在保存回答”或“正在保存对话”，不继续显示“正在回答”或提前显示完成。插件结果读取期间仍是“正在准备回答”，不会把读取误写成保存。
- 当前请求的等待、思考、输出和最终保存优先于旧错误和后台配置检查；没有实时请求时，恢复登录、同步和新发生的阻碍优先于旧回答。未解决的历史读写错误会显示“历史尚未同步”，不因屏幕上已有完整回答而隐藏。历史消息不会自行恢复成进行中的动画。

插件授权缺失或连接更新时显示“插件需要处理 / Plugin needs attention”；插件结果不可用或达到续答限制时显示“暂时无法续答 / Cannot continue yet”。续答失败时，状态说明为“结果已保留。请点击‘继续回答’重试，无需重新执行工具。”，恢复入口只用于当前可恢复的续答。这些同样属于 `paused` 视觉状态，不会自动重新执行工具。聊天与插件行为边界见 [DeepSeek 对话](deepseek-chat.md)、[MCP 宿主](mcp-host.md) 和 [插件对话设计](plugin-chat-2026-10-26.md)。

## 首页与消息布局

[聊天页面](../native/src/prototype/chat.tsx) 统一采用可滚动内容区和底部输入区。空态中，小Q形象与“有什么想聊的？”位于内容区，“写点什么”“一起想想”只在草稿为空时出现；输入框不再与全部状态文字一起挤在页面中央。页头使用“小Q / Q”，原有侧栏、历史、服务和社交消息入口保留。

有消息时，输入框上方显示一行小Q、当前状态与详情入口；消息里的助手头像保持静态，模型选择保留在输入框工具行。键盘出现、窗口高度小于 580、实际可用高度小于 420 或系统字体缩放大于 1.4 时收起空态大图与欢迎内容，改用紧凑状态栏；紧凑模式暂不展开状态说明。输入区根据实际可用高度限制最大高度，极矮横屏或键盘空间不足时可以滚动到发送等操作；正常手机高度不产生额外输入区滚动。输入文字保持 16px，输入框可随内容增长，并限制最大高度。

原先输入框下同时铺开的登录、历史、配置与错误说明改为简短通知入口。未登录时保留“登录后开始对话”；已登录时不再在输入框下重复显示用户名和退出按钮，账号入口仍在侧栏。所选插件仅显示紧凑名称标签和带可访问名称的移除按钮，不再展开工具执行说明或余额快捷按钮；银行转账表单入口放在“+”菜单。

“对话状态 / Chat status”详情面板按现有状态展示错误原因、重新检查登录、重新检查连接和历史同步操作。历史提示复用 `historyErrorMessage`，区分云端校验拒绝、版本冲突、会话数量或大小上限、保存结果待确认以及登录过期，以可理解的文案说明如何保留未同步内容和恢复，不在界面展示机器错误码。历史版本冲突仍保留“重载云端版本（替换未保存内容）”，并在操作前明确说明会替换本机尚未保存的内容。消息级错误和手动重试仍靠近相应回答；同步或最终保存期间不允许启动下一次回答。

插件对话优先展示业务内容与可用结果，不默认铺出原始工具名、JSON、端点或回执 UUID。当前用户发起、且服务端明确支持的受信内置银行余额和流水查询可自动执行并续答；转账和未获可信只读策略的远程调用仍须确认完整业务内容。第三方声明自己只读不能获得自动执行权限，旧服务缺少能力时仍走人工确认。模型完整回答后隐藏重复工具文字，保留原生图片和经校验的简短模拟转账回执；续答失败时保留真实结果。业务结果仍由插件卡片和服务端记录表达，不能由小Q头像的笑脸或对勾作出判断。

本次信息组织延续 [白色青蓝设计记录](ui-research-2026-10-18.md) 的聊天优先和渐进展示原则；该历史文档中的纯前端描述不作为当前网络能力基线，当前对话能力以 [DeepSeek 对话](deepseek-chat.md) 为准。

## 动态效果与可访问性

- 三主题和中英文继续使用现有 `useDesign`，不用角色颜色代替状态文字。输入框、发送、停止、模型选择和详情入口保留可访问名称；新增状态操作按 iOS 44pt、Android 48dp 设置触控目标。
- 小Q图形是相邻状态文字的装饰，隐藏于无障碍树；主状态栏提供完整状态标签、`busy` 属性和 `polite` 更新，避免让多个头像重复朗读。
- 只有真实进行中的操作会设置 `busy`。角色处于 `thinking` / `streaming` 且允许动画时，主体仅有 2.6 秒轻微入态动作；角标中的圆点或箭头持续低幅明暗变化，表示操作仍在进行。空闲、停止、错误和完成状态不循环装饰动画。
- 进入后台、卸载或启用 Reduce Motion 时取消动画；打开详情、模型、工具、转账、登录或 AI 授权面板时，页面上的角色停止活动动画。减少动态效果下仍保留静态表情、角标和文字。
- 小尺寸消息头像不显示复杂角标；主状态栏使用 52 的形象保留活动反馈。状态变化不依赖动画才能被理解。
