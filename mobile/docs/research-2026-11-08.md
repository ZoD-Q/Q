范围由用户确认：完善现有六家金融服务的状态/恢复和原生界面，新增 Tavily 搜索/正文提取、FRED 独立临时研究、SEC 主文件 HTML 原文。未接入 Trading Economics 等后续候选，未购买数据、部署、发包或自动合并。

## 行为与兼容

- 金融目录按研究/宏观和金融数据分组，连接各阶段显示主要下一步操作，保留三主题及中英文。默认目录版本1仍返回原六家；版本2提供新增两家，旧服务器缺失能力明确显示。
- Tavily 只开放固定 keyless 搜索/正文提取；实际共享额度错误即使使用 HTTP 200 也拒绝当作研究成果。Alpha Vantage 增加三项研究工具选择，仍核验实时 schema 和账号权益。401/403/402/429与网络失败区别呈现。
- FRED 三项研究工具使用实时 schema 和专用原生表单。查询、结果及工具快照不进入缓存、调用存档、聊天历史或模型；退出、后台、切号及版本变化清空。页面告知临时性并提供条款和非背书说明。授权秘密沿现有加密和账号/连接/版本绑定保存；固定 FRED 例外不扩大通用插件认证范围。
- SEC 目录验证主体与 accession 后派生官方主文件地址，HTML 纯文本、有界解析、真实章节与段落来源。翻页必须绑定 SHA256；PDF/其他格式标为未读。原文草稿保留完整引用和限制，不自动发送。主助手独立协商 `filing_research_version:1`，共享原有三结果及上下文预算。

详细合同与覆盖见[金融插件](financial-plugins.md)、[公司研究](company-research.md)、[应用主助手](app-assistant.md)及[API 合同](../../backend/contracts/api.md)。

## 真实来源与原生界面

2026-11-08，iPhone17 / iOS26.5 / Expo Go58，本地测试身份显式连接独立Rust API与独立数据库，无模型或供应商私密密钥。已实际查看暖纸主题的八家分组目录、FRED详情与不保存告知，添加后显示需要授权；本地未配置OAuth时按钮不可执行，不能误报授权完成。

白昼主题下，原生AAPL搜索分别返回SEC和Wikidata候选，选择SEC主体完成结构化财务读取，再进入原文披露。实际 Rust `SecFetcher` 在保持 no_proxy、DNS/IP绑定、固定主机和禁止重定向的条件下取得20项目录及Apple 2026-11-03的10-K主HTML：1,285段、24章节、无提取截断。SHA256为 `9a3ee612c32965fc9ac705a4a7989b6508b72111017ee0699ed2c41c45ab26cd`；风险因素章节offset146返回同一hash，从界面段落147开始显示。引用正文段落148后，新对话草稿保留原文、文件版本、段落锚点和未读范围，未发送模型。此前预检曾遇到直连TLS超时；本次后续真实路径成功不代表来源持续可用。

Tavily匿名Python搜索曾取得两项真实公开来源。Rust宿主初始化、工具发现和业务请求传输通过，但后续搜索/提取被供应商共享额度拒绝（包括HTTP200内的月额度提示）；未付费、填写奖励问卷或切换出口规避额度，不能宣称Rust正文提取已成功。FRED仅验证公开元数据，真实个人授权后的schema与业务结果未验收；本地OAuth/数据不落存证明来自HTTP替身与隔离数据库测试。

本阶段未覆盖Android、真机、最大字体与真实模型原文续答。FRED完整临时查询的原生视觉仍受真实授权条件限制；后台、离页、切号和迟到响应由组件与服务端测试验证。后续合并验收若扩充覆盖，应在下节单独记录，不将既有通用平台回归当成本功能供应商验收。
