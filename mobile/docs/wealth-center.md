## 模拟行情与数据口径

- `core.ts` 为纯函数：`nextCandle`/`seedCandles`（rng 注入，可测）、`todayPct`/`todayPnl`（权益单位 = 基金部分市值）、`windowBounds`、筛选函数。页面层持有定时器与状态（setInterval 1600ms，卸载清理）。
- K 线标的明确标注：「我的组合 · 基金部分」，权益基数 ≈ ¥105,990；总资产 = 持仓市值 + 今日权益浮盈。
- 全部数据为演示模拟（`DEMO_NOTE`、`DISCLAIMER` 常量 + 页内标注），与港币钱包、模拟银行资金完全分开；真实行情 API 接入点即 `nextCandle` 调用处。

## 合规边界（M6 红线逐条执行）

- 「金融信息与数据服务」定位：不构成投资建议、不承诺收益、不推荐产品；业绩基准非承诺收益。
- 基金页为公开资料列举（排名不分先后），申购在管理人直销或持牌销售机构完成，小Q不代销、不代收款；不固化费率与收益数字。
- 货架为示例类别非推荐；R4/R5 购买前需持牌机构正式风险测评；自评不构成适当性结论。
- 外跳白名单：`trustedExternalUrl`（https + 允许清单）。
