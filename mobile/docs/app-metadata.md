# KAI小Q应用资料

**软件全称：** KAI小Q

**中文简称：** 小Q

**英文简称：** xiaoQ

**包名（iOS Bundle ID）：** `com.kaicloud.xiaoq`

**版本号：** V0.1.0

**运行平台：** Android、iOS

**APP简介：**

KAI小Q是一款以AI对话为核心的智能助手，帮助你解答疑问、梳理思路、辅助创作。你可以按需连接开放插件，确认后使用工具完成任务，也可以添加好友、进行一对一文字交流，体验阅后消息与关系标签，让对话、服务和日常交流更加便捷。
