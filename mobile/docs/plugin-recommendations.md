# 对话中的能力推荐

## 行为与边界

用户在普通聊天或深度思考里表达需求，消息成功保存后，客户端并行请求推荐。正文独立完成；推荐失败、超时或容量不足不改变正文的错误、停止或重试状态。推荐最多三项，第一项突出，保留连接、授权、更新确认与不可用状态；无关聊天不因新增插件出现推广。

卡片使用当前主题的背景、文字与强调色，连续圆角、清晰的标题/原因/动作层级，按钮至少 48 点；继承中英文、系统字体缩放、减少动态效果及现有轻触反馈。插件描述是外部数据，不能决定权限、执行动作或生成导航地址。

点击已连接插件会取得专属对话，带入原问题和最多两轮完整的普通上下文。当前插件会话不把旧插件私有结果传给新插件。首次确定创建成功后才自动继续；重复点击、首次响应丢失、刷新或重启只恢复同一目标，用户点“继续原问题”恢复未开始的任务。目标已删除时旧卡失效，不重新创建。写操作、付费或其他第三方工具保留原确认步骤。

尚未连接、待授权或待确认更新时，打开现有连接界面并定位服务；返回后保留“继续原问题”。公开市场/保险查询建立普通承接对话，复用应用主助手执行器；其他模块只导航到白名单入口，并预填其支持的条件。同回合已有对应入口时合并卡片。已选择插件的会话默认沿用原插件，明确更换时才推荐。

## 动态目录

目录来自固定模块、现有金融服务配置、20 家模拟银行及**当前账号自己的**有效 MCP 连接。银行能力与金额始终是模拟。远程工具取自经过校验的运行时快照；访问状态、连接版本和能力指纹每次从数据库读取，不依赖客户端发布或人工刷新。未知发布者的新标准 MCP 连接也能进入当前账号候选。

每次检索得到稳定身份、能力描述、任务词、访问条件和版本摘要；召回最多 12 项，精确指定服务走规则，其余最多一次 Flash 从实际候选选择 0–3 项。模型不生成名称、权限、费用或动作。返回前再次校验目录，点击时重新核对归属、版本、源消息摘要和可用状态。待授权可使用允许显示的描述；授权后工具不进入公共目录。

目前仓库没有已验证公开发布许可、robots/noindex 的动态公共索引，`plugin_services.anonymous_card` 也不是发布许可。因此不把所有个人添加的服务向全体用户公开。首版公共候选限于宿主固定公开能力；动态 MCP 按账号隔离。新的特殊认证或执行方式仍需适配代码。

## 保存、恢复与指标

推荐独立保存在 `ai_recommendations`，绑定账号、源会话、源消息和实际上下文摘要，不修改正文历史快照。每个会话最多保留 100 条，卡片有效期七天；源会话清理和账号注销级联删除推荐。目标对话独立保留原历史规则。每个“推荐＋候选”只有一个承接目标，目标被删除后保留不可重新创建的标记，直到源推荐清理。

原生端只在 SecureStore 按账号保存待继续的标识符，不保存原始工具数据、凭据或新副本的聊天内容；Web localStorage 仅保留按账号隔离的无令牌标识符，不保存正文。切号、离开聊天、后台、撤销 AI 同意和组件卸载会取消推荐/选择并隔离延迟返回。历史列表仅恢复显示，不调用模型或业务工具。

服务端只记录数量、耗时、模型 token 用量及安全错误码，不记录聊天正文、插件结果或凭据。推荐和选择表可汇总卡片产生量与选择量；`outcome/finished_at` 观察承接首个问题的终态。`answered` 是回答完成，`tool_succeeded` 还要求所属连接的调用记录成功；这两个值不证明用户目标已完成或真实金融交易成功。后续真实业务转化需按服务的可信回执另行定义。

## 开关与验证

`Q_AI_RECOMMENDATIONS=false` 默认关闭；启用时 `/v1/ai/status` 返回 `recommendations_version: 1`。旧服务无此字段时客户端不请求推荐。部署模板透传该开关，修改代码不等于已部署或已启用。

推荐总预算五秒；服务实例只允许一个活动生成，一个低优先级模型排名，并共用现有模型总并发与每账号请求预算。正文可取消排名并优先取得连接；排名需留下至少四次正文调用额度，覆盖公开工具查询和最终解释。此门禁沿用当前单实例架构，不能宣称多实例分布式配额。

自动验证包括客户端 `test:chat` 的推荐交互/解码/恢复测试、后端目录与匹配样例、独立 PostgreSQL 下 `--all-features --test recommendations -- --ignored`，并加入两端 CI。离线召回与规则指标不等于真实 Flash 排名指标；启用前仍应使用代表性问题做实际模型质量评测。

原生 UI 验收可用 `backend/examples/recommendation_preview.rs`：只接受回环地址的独立 `q_recommendations_preview` 数据库，模型为明确标记的本地替身；移动端显式设置 `Q_LOCAL_API_TEST=1`、`EXPO_PUBLIC_API_URL=http://127.0.0.1:8789`。不读取业务数据库、不调用实际模型/银行，不据此宣称供应商实账验证完成。
