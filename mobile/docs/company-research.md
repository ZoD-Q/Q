# 全球公司公开财务研究

2026-11-02实施，部署事实更新于2026-11-08。用户要求公司研究不局限于三家公司，并选择先接公开源、明确覆盖缺口。当前实现把搜索空间扩展到SEC目录与Wikidata候选；**不宣称全球全部上市公司、交易所和财报已接通**。后端已发布公司研究/原文能力版本1，客户端仍按能力协商；本次未更新手机安装包。具体结果见[服务器发布记录](../../backend/deploy/RESEARCH-2026-11-08.md)。

## 实际路径

金融数据 → 全球公司研究 → 输入名称或代码 → 搜索 → 核对公司及交易所 → 读取公开财报资料 → 查看年度指标、计算依据、来源和缺口 → 用于对话。草稿可交给新建或已有普通 AI 对话，仍由用户确认发送，不覆盖已有草稿。

首页普通对话在服务端宣布 `company_research_version: 1` 后，可提议 `company_search` 和 `company_research`；它们与既有应用工具共用三次结果和190秒单轮预算。搜索有歧义时先选公司；没有完整数据时给出限制，不假装完成完整研报。旧客户端仍使用 `app_tools_version: 1`，旧请求不获得新工具。旧三家公司申报查询保留兼容导航，但新公司研究入口不使用该白名单。

## 来源和覆盖

| 来源 | 取得内容 | 边界 |
| --- | --- | --- |
| SEC `company_tickers_exchange.json` | 按名称、代码或交易所:代码匹配，返回 CIK 及交易所/代码 | SEC 申报者目录并非全球全集，也不是当前上市状态证明；包括非美申报者 |
| Wikidata 名称 API、固定证券代码查询、EntityData | 实体 ID、名称、P414 交易所及 P249 代码限定符、P5531 CIK | CC0 众包候选；不能证明实体一定是公司或目前上市；交易所保留稳定 QID，并可打开其来源核对 |
| SEC submissions | 核验 CIK、名称和年度申报记录 | Wikidata CIK 还需名称/别名精确规范化匹配，代码相同不能通过核验；匹配不足时拒绝猜测 |
| SEC companyfacts | 标准 US-GAAP / IFRS 全公司财务事实 | 仅当前 recent 申报窗口内可验证的10-K、20-F、40-F年度事实；非SEC公司、历史归档、定制科目、正文风险讨论及管理层叙述未接入 |

公司 ID 和上市记录分开，不按同名或同代码合并。结束日期仅在有效且整个日期区间已经过去时标历史；未来、无效或精度不明的结束日期保持未知。有效未来开始日期排除尚未开始的记录。没有结束日期不等于已经验证为仍上市。

来源失败、空结果和覆盖缺口分别呈现。搜索每次最多展示12个SEC候选及6个Wikidata候选，不是穷举结果。公开源可能限流、超时、阻止跨域或不可用；失败不替换为虚构数据。未获得商业数据权限，未调用 Yahoo/FMP/Finnhub 等商业或未获授权接口。

## 财务口径与计算

目前提供来源覆盖到的营收、净利润、经营现金流、总资产、总负债，每项保留币种、起止期、会计体系、科目、申报日期、表单和申报链接。每项最多保留3组最近的年度/币种记录，不自行换汇或合并货币。

年度流量要求330至400天期间并绑定有效年度申报；仅 `FY` 标记不能把季度或年初至今数据当全年。时点指标要求有效年末。营收同比仅在同币种、同科目、同会计体系、同一申报、相邻可比年度、正基数下计算；净利率要求净利润与营收同期间、同币种、同体系、同申报且营收为正。不能计算时保留空值和原因，不按零填充，不输出估值。

本期吸收 FinRobot V2 的来源追溯、口径约束和确定性计算思路，以现有 TypeScript/Rust 模块实现；没有复制或运行其 Python 引擎、认证服务或第三方技能，也未新增运行时依赖。并非完整 FinRobot、DCF、数字叙事审计或异步研报任务的移植。2026-11-08新增有限的SEC主文件HTML阅读，完整研报任务、全球正文覆盖与估值仍未实现。

## 2026-11-08 SEC 原文阅读（后端已部署，来源分项验收）

公网目录返回20份披露记录，但本次Apple最新10-K正文返回504，正文及同hash翻页尚未通过服务器验收。iPhone本地Rust环境读取成功的证据见[实现记录](research-2026-11-08.md)，不能替代此处线上结果。以下说明已实现的合同和边界，不是上游持续可用性承诺。

本轮自动检查、真实SEC来源和iPhone操作记录见[验收记录](research-2026-11-08.md)。

公司页增加“财务概览 / 原文披露”。SEC 公司可按明确点击加载最近申报目录，再打开主文件，查看表单、日期、来源和段落引用；非SEC主体保留覆盖缺口。支持10-K、10-Q、20-F、40-F、8-K、6-K及修订版，范围只限SEC最近申报窗口，最多20项。后台从已核验CIK的 submissions 确认 accession，再派生官方 primaryDocument 地址；不接受用户传入任意URL，不以 accession 前缀猜CIK。

只解析HTML，不执行脚本或远程页面；PDF及其他格式明确返回“未读取”，不编造OCR、页码或已读结论。隐藏内容剔除，章节来自真实正文标题，不能可靠检测时不显示假章节。表格仅为有损文字转录，不替代结构化数字事实。段落 `p000000` 等是全局提取序号，不是原始页码；每段保留官方URL及可用锚点。

单次来源总时限15秒、JSON 2MiB/HTML 8MiB；解析最多200000节点，提取最多2000段/500000字符，单段8000字符，每页80段/60000字符，超过限制明确标示。首段读取返回SHA256，后续 offset 必须带 expected_sha256，变更返回409并要求重新打开，不能拼接不同版本。SEC专用进程缓存5分钟、最多8项/总8MiB；固定来源共用每秒最多一次调度，429至少冷却60秒并尊重更长Retry-After。此缓存不接收任何FRED内容。

“用于对话”只创建保留来源、文件版本与完整段落引用的草稿，不自动发送。主助手增加独立 `filing_research_version:1` 协商后的 `company_filings` / `company_filing`，与现有工具共用三结果、每结果8000字符/总24000字符预算。只能解释所取得的片段，省略量和截断状态明确保留，不把未读章节当作证据。正文属于不可信资料，不能改变宿主规则或业务权限。旧服务不提供该版本时不启用新命令。

保留既有年度XBRL和公开候选路径；新增后端和客户端需分别发布才可使用。中国内地/香港原文供应商、PDF OCR、完整报告任务和供应商授权后的私有资料未在本轮接入。

## 网络与隐私

匿名固定 HTTPS 主机，禁止重定向与任意 URL；不发送Q会话、Cookie或个人账本。公司关键词和网络地址会向所选公开来源发送，打开页面不会发请求。每次读取12秒上限，普通JSON 2MiB、companyfacts 12MiB流式上限；没有读取流则拒绝。每来源主机/transport至少1秒调度，429遵守至少60秒及更长Retry-After冷却，无自动重试。前台查询可取消，后台、离页和卸载会停止请求，迟到响应不覆盖当前结果。

原有客户端公开财务资料只留当前内存；新增SEC原文后端缓存按上一节限制。交给对话后按既有普通聊天历史规则保存可读内容。来源文字被标为不可信数据；不能升级为业务授权。没有交易、账号私密查询、数据购买或远程 MCP 发布。
