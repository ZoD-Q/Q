# 插件工作台

2026-10-20。当前交付为现有 Expo 客户端内的材料准备与本地检查工具，入口是侧栏「插件工作台」、插件目录「接入我的插件」，或 `/?view=plugin-workbench`。

## 开发者看到什么

先回答「给 Q 什么」：一个稳定 HTTPS 入口，优先独立 Server Card URL。开发者自行部署 MCP 服务与 Card；本通道不上传源码或压缩包，不增加开发者账号、Registry 注册、人工上架审核等前置条件。

- **已有接入链接**：默认粘贴一个链接并继续，带入「我的连接」真实添加页面；未登录时保留该链接，登录后仍需核对并确认。默认自动识别，四种显式类型及本地 JSON 检查放在高级选项，不按文件名猜测类型。
- **生成接入文件**：先填写插件名称、用途和可选所有者，连接参数与按需能力分组展示；生成 Card、可选 Catalog、可选静态介绍页、双语接入清单。输出只展示为文本并支持复制，不执行 HTML，也不代表已发布。
- **所有者**：通过标准允许的 `_meta["com.kaicloudpay.q/owner"].name` 写入 Card，介绍页也展示。它是发布者自声明，不是小Q认证或账号权限；旧草稿、旧插件缺少字段仍兼容。非法的本地填写会提示修正，远端无效的可选声明不会阻断合法插件。
- **材料说明**：必需的运行中 MCP 服务和独立 Card，与域名发现、账户授权、Apps UI、公共收录等条件性要求分开。
- **连接状态**：添加、按需授权、首次调用均保持未验证，不能把本地格式通过当成接通；个人连接与公共索引条件分开。

草稿、入口、粘贴 JSON 和本地检查结果仅在会话内保留，切换页面不丢失，刷新会清空；不写本地持久化存储。材料生成与本地检查不发送草稿到后端；用户继续到「我的连接」查找服务时，才提交入口链接。修改输入立即使对应检查或生成结果失效。

## 实现边界

- `src/prototype/plugin-workbench/materials.ts` 是无网络纯逻辑。它不是完整 schema 验证器，也不提供服务端 SSRF 防护、DNS 检查、可达性或授权验证。
- 保留有效路径、查询顺序、重复查询参数和尾斜杠。拒绝非 HTTPS、嵌入凭据、显式私网地址与可识别秘密；普通 `key/code` 参数保留并提示检查。敏感错误不回显输入。
- Card 检查大小与嵌套边界、基本字段及至少一个符合 Q 基线的端点；附加端点不必都支持选定版本。运行时能力和授权配置不写入 Card。
- 生成可选 Catalog 时避开 Card/MCP 地址；固定根 Catalog 冲突会要求修正。域名发现示例默认使用 Card 的来源，UI 明确该假设；规范允许第三方托管与不同发布域名。
- Catalog 和介绍页始终可作为可选材料查看，不要求先选择公共收录或域名发现。介绍页指向的 Catalog 必须一同部署。
- 新增 SDK 58 对应 `expo-clipboard ~58.0.3`，用于原生与网页复制。只响应用户复制操作，不读取剪贴板。成功反馈在当前弹层中显示；失败保留可选中文本。

交互复用现有 `Page / Input / Action / Choice / Sheet` 与语义主题，白底青蓝、双语，宽屏主表单与材料说明并列、窄屏顺排。没有引入新 UI 框架或数据库迁移；配套插件 API 增加自动识别和所有者展示字段，不改变账本。

## 验证

从仓库根目录：

```sh
npm --prefix mobile run test:plugins
npm --prefix mobile run typecheck
npm --prefix mobile run lint
npm --prefix mobile run export:web
```

自动检查覆盖四类入口、URL 身份、凭据与本地地址、JSON 边界、兼容端点、按需材料和地址冲突。实际 UI 检查需覆盖入口、错误反馈、生成/复制、切页恢复、窄屏输入和主题/语言；只有实际运行过的平台才记为验收。

此前工作台验证：24 项纯逻辑测试、TypeScript、ESLint 与 Web 静态导出通过。独立代码审查发现的查询参数误拒、目录地址冲突、可选材料入口、附加端点兼容、弹层复制反馈和 JSON 错误定位均已修复并复核。iPhone 18 Pro / iOS 27 的实际预览已检查工作台入口、首屏布局、地址输入及 HTTP 错误反馈；弹层复制全流程和其他主题/语言尚未完成设备验收，Android 未实测。浏览器自动操作在当前环境中被关闭，未宣称完成浏览器点击验收。

2026-10-20 所有者与简化接入变更：TypeScript、ESLint、39 项插件测试、utils/video/api-workbench/account/social/chat 测试、API 类型再生一致性与 Web 静态导出通过。测试新增所有者长度与控制字符边界、旧资料兼容、HTML 转义、链接与显式入口类型传递、过期会话重登后的意图保留和原生登录弹层交接。独立代码审查及验收修复的增量审查已通过。

此次新界面已在 iPhone 18 Pro Max / iOS 27、Expo Go 58.0.4 完成实际检查：填写 `mandow` 并生成含所有者的 Card、复制成功反馈、生成链接与显式入口类型完整带入、默认自动识别、高级选项、候选与连接列表/详情/调用中的所有者展示、显式确认执行和照片翻页。使用独立本地 API、图库及 QA 账号；未接触线上账号或供应商。

未登录带链接、取消后重新打开登录、错误密码后重试、成功登录后打开添加表单均通过；在独立测试库使该 QA 会话到期后，再登录仍保留完整链接与类型。实际修复并复测了窄屏材料弹层底部按钮压缩，以及 iOS 登录弹层关闭与添加弹层打开的冲突：底部按钮使用自然高度，登录交接等待原生关闭回调，不用任意延迟。软件键盘下链接及继续按钮可见，light/dark/warm 与中英文页面均已查看。结束后退出测试账号并恢复白昼主题。Android、真机、浏览器点击和横向滑动未覆盖；这些检查不代表固定公网地址已部署。

真实远程发现、个人连接、OAuth/CIMD 和运行时调用现由独立的“我的连接”提供，详见 [MCP 宿主](mcp-host.md)。本材料工作台仍保持无网络纯逻辑；Apps 沙箱尚未实现。完整目标遵守 [Q 插件接入规范](../../backend/docs/plugin-integration.md)。
