# 插件工作台

2026-10-19。当前交付为现有 Expo 客户端内的材料准备与本地检查工具，入口是侧栏「插件工作台」、插件目录「接入我的插件」，或 `/?view=plugin-workbench`。

## 开发者看到什么

先回答「给 Q 什么」：一个稳定 HTTPS 入口，优先独立 Server Card URL。开发者自行部署 MCP 服务与 Card；本通道不上传源码或压缩包，不增加开发者账号、Registry 注册、人工上架审核等前置条件。

- **已有接入链接**：支持 Card、域名、介绍页与 Catalog 四种入口，检查本地链接格式。可展开粘贴 Card JSON，检查关键字段，错误显示具体路径。
- **生成接入文件**：按插件信息、连接地址、按需能力分步填写，生成 Card、可选 Catalog、可选静态介绍页、双语接入清单；输出只展示为文本并支持复制，不执行 HTML。
- **材料说明**：必需的运行中 MCP 服务和独立 Card，与域名发现、账户授权、Apps UI、公共收录等条件性要求分开。
- **连接状态**：添加、按需授权、首次调用均保持未验证，不能把本地格式通过当成接通；个人连接与公共索引条件分开。

草稿、入口、粘贴 JSON 和本地检查结果仅在会话内保留，切换页面不丢失，刷新会清空；不写本地持久化存储，不发送到后端。修改输入立即使对应检查或生成结果失效。

## 实现边界

- `src/prototype/plugin-workbench/materials.ts` 是无网络纯逻辑。它不是完整 schema 验证器，也不提供服务端 SSRF 防护、DNS 检查、可达性或授权验证。
- 保留有效路径、查询顺序、重复查询参数和尾斜杠。拒绝非 HTTPS、嵌入凭据、显式私网地址与可识别秘密；普通 `key/code` 参数保留并提示检查。敏感错误不回显输入。
- Card 检查大小与嵌套边界、基本字段及至少一个符合 Q 基线的端点；附加端点不必都支持选定版本。运行时能力和授权配置不写入 Card。
- 生成可选 Catalog 时避开 Card/MCP 地址；固定根 Catalog 冲突会要求修正。域名发现示例默认使用 Card 的来源，UI 明确该假设；规范允许第三方托管与不同发布域名。
- Catalog 和介绍页始终可作为可选材料查看，不要求先选择公共收录或域名发现。介绍页指向的 Catalog 必须一同部署。
- 新增 SDK 58 对应 `expo-clipboard ~58.0.3`，用于原生与网页复制。只响应用户复制操作，不读取剪贴板。成功反馈在当前弹层中显示；失败保留可选中文本。

交互复用现有 `Page / Input / Action / Choice / Sheet` 与语义主题，白底青蓝、双语，宽屏主表单与材料说明并列、窄屏顺排。没有引入新 UI 框架，也没有改动业务后端、账本或迁移。

## 验证

从仓库根目录：

```sh
npm --prefix mobile run test:plugins
npm --prefix mobile run typecheck
npm --prefix mobile run lint
npm --prefix mobile run export:web
```

自动检查覆盖四类入口、URL 身份、凭据与本地地址、JSON 边界、兼容端点、按需材料和地址冲突。实际 UI 检查需覆盖入口、错误反馈、生成/复制、切页恢复、窄屏输入和主题/语言；只有实际运行过的平台才记为验收。

本次结果：24 项纯逻辑测试、TypeScript、ESLint 与 Web 静态导出通过。独立代码审查发现的查询参数误拒、目录地址冲突、可选材料入口、附加端点兼容、弹层复制反馈和 JSON 错误定位均已修复并复核。iPhone 18 Pro / iOS 27 的实际预览已检查工作台入口、首屏布局、地址输入及 HTTP 错误反馈；弹层复制全流程和其他主题/语言尚未完成设备验收，Android 未实测。浏览器自动操作在当前环境中被关闭，未宣称完成浏览器点击验收。

真实远程发现、个人连接、OAuth/CIMD 和运行时调用现由独立的“我的连接”提供，详见 [MCP 宿主](mcp-host.md)。本材料工作台仍保持无网络纯逻辑；Apps 沙箱尚未实现。完整目标遵守 [Q 插件接入规范](../../backend/docs/plugin-integration.md)。
