# API 工作台：个人可灵视频连接

API 工作台是用户主动启用的业务网络入口，复用 Q 身份服务。聊天、钱包、保险、插件和原视频演示不因此成为已接通的服务。独立 Web 产品仍未实现。

## 用户流程

1. 从侧栏「API 工作台」或视频创作页进入，用现有 Q 账号登录或注册。
2. 新建自己的可灵连接，选择账户区域并输入供应商凭据。凭据只短暂存在输入状态，经 Q 后端加密保存；界面不读回密钥，也不把保存成功称为授权验证成功。
3. 输入画面描述，选择已支持的时长和比例；确认提示词会发往可灵，并由自己的可灵账户承担费用后提交。
4. 查询持久化任务。页面离开、刷新或重新登录后，可重新加载任务；超时不等于供应商取消，也不自动再次提交。
5. 成功后播放供应商返回的视频。链接受供应商保留期限约束；当前不复制到 Q 云存储、不上传广场，也没有真实广告折扣。

## 范围

首批为可灵文生视频适配器，具体模型及认证按当前合同列出的支持范围。图生视频、回调、批量任务、其他供应商和任意自定义 URL 后续独立接入。品牌优惠与 QDC 都属于原演示，不能用作供应商实际报价。

连接撤销会删除加密凭据并停止后续使用；已发出的供应商任务可能继续运行和计费，撤销不承诺取消。任务记录仍保留。需要更换凭据时建立新连接，历史任务不静默切换到另一个账户。

## 本地运行

默认 `npm --prefix mobile run dev` 仍只启动前端。仅本地联调时单独启动 PostgreSQL 和 Rust API；服务端设置 `Q_VIDEO_ENCRYPTION_KEY`，值为随机 32 字节的标准 Base64（不能放在 `EXPO_PUBLIC_*`）。密钥缺失时功能关闭，不降级明文保存。请妥善备份该密钥；当前没有自动轮换/恢复服务。

所有普通客户端默认访问 `https://q.kaicloudpay.com`。仅显式本地测试设置 `Q_LOCAL_API_TEST=1` 与 `EXPO_PUBLIC_API_URL`：浏览器/iOS 模拟器可用 `http://127.0.0.1:8787`，Android 模拟器访问宿主用 `http://10.0.2.2:8787`。独立测试应用的原生项目须重新生成；不要覆盖正式应用。后端 CORS 需允许相应浏览器源，不可把真实供应商凭据通过公网明文 HTTP 传输。

测试使用独立 PostgreSQL 测试库及显式编译启用的本地供应商测试替身，测试视频不是可灵模型生成。这能验证请求、任务生命周期与结果缺失/失败处理；没有用户自己的供应商凭据时，不代表真实账户余额、权限和生成质量已验收。

## 已核对的支持范围

Kling 2.6，`model_name: kling-v2-6`，`mode: pro`，`sound: off`，时长字符串 `5/10` 秒，比例 `16:9/9:16/1:1`。国内接口 `api-beijing.klingai.com`，国际接口 `api-singapore.klingai.com`。使用单一 API Key，不要求用户自行生成 JWT。

官方接口依据（2026-10-19 核对）：[API Key 鉴权](https://kling.ai/document-api/api/get-started/authentication.md)、[国内接口](https://klingai.com/document-api/api/get-started/authentication.md)、[兼容版文生视频](https://kling.ai/document-api/api/video/3-0-omni/text-to-video/legacy)、[更新记录](https://kling.ai/document-api/updates/api.md)。文生视频 GET 路径可使用原 external_task_id；不假定供应商 POST 幂等。

当前结果播放仅接受 `klingai.com` 官方域下的 HTTPS 地址，保留签名查询参数。不支持的资源域显示明确状态，不跳转未知网址。官方未提供完整生成媒体域列表，真实账户联调仍需核实结果域和有效期。

实现复用 Expo SecureStore、Video 与现有主题/表单，不新增移动端依赖。后端新增 `reqwest`（TLS、超时、受限供应商 HTTP）及 `aes-gcm`（认证加密），均由 Cargo.lock 固定解析版本；未引入额外服务或业务框架。服务端限流当前为进程内实现，密钥轮换、生产部署和完整运维另行设计。

手动查询已完成任务会尝试刷新供应商的临时视频地址。刷新失败时保留上一次安全地址和成功状态，并提示查询失败；这不会创建第二条供应商任务。若设备待确认记录无法读取，仍可查看服务端历史与撤销连接，但新提交保持禁用，不能通过覆盖原记录绕过恢复保护。
